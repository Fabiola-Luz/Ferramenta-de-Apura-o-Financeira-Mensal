# Ferramenta-de-Apura-o-Financeira-Mensal
Ferramenta de entrega e consulta de comprovantes ao setor fiscal para apuração de competência
Ferramenta de Apuração Financeira Mensal

Sobre o projeto

Este projeto foi desenvolvido em Excel durante o desafio da DIO, com o objetivo de organizar e facilitar a apuração mensal de informações financeiras.

A ferramenta permite reunir e organizar dados como faturamento, movimentações financeiras e extratos bancários, facilitando a conferência e a consolidação das informações de cada período.

A estrutura foi desenvolvida acompanhando os conceitos apresentados durante as aulas, com adaptações de layout e organização visual.

Principais recursos

Organização do faturamento mensal;

Registro e organização de movimentações financeiras;

Organização de informações provenientes de extratos bancários;

Consolidação dos dados por período;

Validação das informações inseridas;

Facilitação da conferência dos valores;

Navegação entre as diferentes áreas da ferramenta;

Estruturação das informações para acompanhamento mensal.

Objetivo

O objetivo da ferramenta é centralizar as informações financeiras de determinado período, tornando mais simples o processo de registro, organização, apuração e conferência dos dados mensais.

A organização dessas informações também pode facilitar análises e controles posteriores, de acordo com a necessidade do usuário.

Tecnologias e recursos utilizados

Microsoft Excel;

Fórmulas e funções;

Validação de dados;

Organização e consolidação de informações;

Recursos de navegação entre planilhas;

Formatação e estruturação de dados.

Desenvolvimento

O projeto foi desenvolvido como parte de um desafio da DIO, utilizando os conceitos apresentados nas aulas como base para sua construção.

Durante o desenvolvimento, foram realizadas adaptações na organização e no layout da ferramenta, buscando criar uma apresentação própria e funcional para a apuração mensal das informações financeiras.
